# Community translations

The English [README](../README.md) and [documentation](../docs/) are the canonical sources. These translations are developer-facing overviews that cover the README narrative, quick start, and documentation map without duplicating every reference page.

Available translations:

- [Tiếng Việt](./vi/README.md)
- [Español](./es/README.md)
- [Português do Brasil](./pt-BR/README.md)
- [简体中文](./zh-CN/README.md)
- [日本語](./ja/README.md)

Translation conventions:

- Commands, package names, file paths, config keys, and provider names stay in English.
- Terms such as `playbook`, `TASK.md`, `DAG`, `checks`, and `Seed` stay visible because users will see them in the CLI and source tree.
- The English docs remain the source of truth when behavior changes.
