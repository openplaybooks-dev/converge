# The Playbook Mark

## Concept

The word "playbook" is unique to Converge in the AI tools space. No other framework calls its workflow definition a playbook. This is ownable territory.

A playbook mark combines the **physical object** (a book, a binder, a page) with the **convergence concept** (pages meeting at a spine, content narrowing to a conclusion).

## Why it fits Converge

- **Playbook** is the product category ("Autonomous AI agent playbooks")
- A playbook is a **plan** that **executes** — PLAN → EXECUTE → VERIFY → REPAIR → SHIP
- Pages = individual TASK.md files
- The spine = the runtime that binds them together
- A bookmark = verification ("this is where we are")
- The book closes = CONVERGED

## Variant Sketches

### A3 — The Bookmark Check (strongest)

A simple bookmark ribbon emerging from the top of a minimal book shape. The ribbon tail forms a checkmark.

```
   ┌─────────┐
   │  ▐▌     │  ← bookmark tab
   │  ▐▌     │
   │  ▐▌     │
   │  ▐▌     │
   │  ▐▌     │
   │  ▐▌  ✓  │  ← ribbon tail = checkmark
   │  ▐▌     │
   └─────────┘
```

- The bookmark = "marked as done" = verification
- The checkmark = the convergence outcome
- Simple, works at 16×16
- Reads as both "book" and "verified"

### A4 — The Binder Ring

A single binder ring or spine ring, with pages fanning from it. The ring is the convergence point. Three pages (RYG) converge into the ring.

```
    ○  ← binder ring (convergence point)
   ╱│╲
  ╱ │ ╲  ← three pages fanning out (RYG)
 ╱  │  ╲
```

- The ring = the runtime (holds everything together)
- The pages = the agents/tasks
- Works well as a standalone icon

## Reference Images (conceptual)

- Sports playbook diagrams (X's and O's on a clipboard)
- O'Reilly animal book covers (recognizable tech book format)
- NFL playbook binders (the physical object)
- Notion's page/book icons
- Obsidian's note-taking icon

## Technical Requirements

- Must work as a single-color silhouette
- Must be recognizable at 16×16 (favicon)
- The "book" should read without the "bookmark" for simpler contexts
- Should pair cleanly with the wordmark "Converge"
