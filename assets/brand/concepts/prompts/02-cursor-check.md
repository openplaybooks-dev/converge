# Concept J: Cursor + Check — Image Generation Prompt

## Prompt

```
A minimal, iconic logo mark for a developer CLI tool called "Converge". The mark combines a terminal cursor with a checkmark. A single geometric shape: a rectangular block cursor (like a terminal █) with a checkmark emerging from or integrated into the right side. The checkmark is formed by a single continuous line that starts as the cursor edge and flows into a ✓ shape. Flat vector style. Clean geometric lines. Dark indigo background (#0F172A). The mark in a single light color (white or light green #34D399). No gradients, no shadows, pure flat vector icon. Premium developer tool aesthetic — like Stripe, Vercel, or Linear brand quality. Minimal, bold, iconic. No text in the image. Symmetrical composition centered.
```

## Design notes

- The cursor + checkmark should read as one unified shape
- Terminal-native feel — developers should recognize it immediately
- The checkmark IS the cursor completing
- Must be distinct from Cursor (the AI editor)'s logo
