# Concept G: Delta Δ — Image Generation Prompt

## Prompt

```
A minimal, iconic logo mark for an AI developer tool called "Converge". The mark is a simple geometric triangle (delta Δ symbol) with three interior lines extending from each vertex toward the center, converging at a single point. The triangle is equilateral, clean, precise. The interior convergence lines create a subtle "three-into-one" reading. Flat vector style. Clean geometric lines. Dark indigo background (#0F172A). The mark in a single light color (white). No gradients, no shadows, pure flat vector icon. Premium developer tool aesthetic — like Stripe, Vercel, or Linear brand quality. Minimal, mathematical, precise. No text in the image. Perfect symmetry. The mark should be recognizable as both a triangle and a convergence symbol.
```

## Design notes

- The Δ is universally recognized by developers (diff, change)
- Three sides = RED, YELLOW, GREEN phases
- Interior lines converging = the core mechanic
- Simplest of all concepts — must be executed with perfect proportions
- The convergence point at center is where the "magic" happens
