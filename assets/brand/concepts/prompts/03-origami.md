# Concept F: Origami Fold — Image Generation Prompt

## Prompt

```
A minimal, iconic logo mark for an AI developer tool called "Converge". The mark is an abstract geometric origami fold: a flat hexagon with three sharp crease lines converging from alternate vertices to the exact center, creating a 3D folded-paper illusion. The fold lines converge to a single bright point at the center. Flat vector style. Clean geometric lines. Dark indigo background (#0F172A). The mark in a single light color (white or light violet #C4B5FD). No gradients, no shadows, pure flat vector icon. The style should feel like premium developer tool branding — Stripe, Vercel, Linear quality. The geometry should be perfectly symmetrical. No text in the image. The fold creates a subtle three-dimensional cube reading from flat 2D.
```

## Design notes

- The hexagon + fold lines must read as "folded paper"
- Three fold lines = three phases (RYG in color version)
- Center convergence point is critical
- Should work as a flat silhouette even without the fold lines
