# Archived RFCs

RFCs in this directory have been **withdrawn** — their partial implementations were removed from the codebase because they were never wired in and the RFC remained in draft status.

To revive an archived RFC:
1. Move it back to `docs/rfcs/`
2. Change `status: withdrawn` to `status: draft` or `status: proposed`
3. The original implementation can be recovered from git history
