# Brand Messaging

## Tagline

**"Define done. Converge gets there."**

## One-Liner

Gap-driven convergence framework for AI agent orchestration.

## Elevator Pitch

Existing AI agent frameworks make you define **how** — steps to take, graphs to traverse, roles to play. But real business workflows aren't about choreographing steps. They're about getting to a known outcome.

Converge lets you define **what "done" looks like** — what files must exist, what checks must pass, what the deliverable looks like when it's finished. The framework continuously measures the gap between current state and target state, generates work to close it, and self-corrects when things fail.

The differentiator: gap-driven convergence, not graph execution. You describe the destination. Converge figures out the route.

## Positioning Statement

**For** businesses and teams **who** need to automate complex, multi-step workflows with AI agents that reliably deliver verified outcomes, **Converge is** a gap-driven convergence framework **that** continuously measures the distance between current state and target state, self-corrects through structured feedback loops, and converges on completion — without requiring you to define how to get there. **Unlike** LangGraph (graph-based), CrewAI (role-based), AutoGen (conversation-based), and OpenHands (step-based), Converge is the only framework where you declare what "done" looks like and the system figures out the rest.

## Key Messages

### For Solo Entrepreneurs

Set up once, run repeatedly. Converge automates your repeatable workflows — content production, client deliverables, data processing — so every hour you spend on growth is an hour not wasted on work you've already figured out how to do.

### For Small Teams (2-15 people)

Encode your team's best practices into playbooks. New hires deliver like veterans. Knowledge stops being siloed, onboarding gets faster, and quality stays consistent across team members.

### For Engineering Leaders

AI workflows that are auditable, repeatable, and don't depend on any single engineer's prompt skills. Filesystem-as-plan means `ls` is your debugger. 270 lines of core logic with 92% test coverage means you can read and trust the foundation.

## Brand Voice Guidelines

### Tone

Professional, precise, confident. Technical depth backed by specifics. First person where appropriate ("I built this because..."). Business-outcome oriented alongside technical claims.

### Avoid

- "Revolutionary", "game-changing", "next-generation", "cutting-edge"
- "AI-powered" (overused, says nothing)
- Superlatives without evidence
- Marketing language that developers and business people see through

### Prefer

- Specific, measurable claims backed by architecture: "270 lines of core logic", "92% test coverage", "4 LLM providers"
- Numbers over adjectives
- Show, don't tell — GIFs, terminal recordings, code snippets
- Include limitations alongside strengths
- Business outcomes: "saves 10 hours/week on client reports" over "supports hierarchical task nesting"

### Long (3 paragraphs)

Converge is an open-source, TypeScript-native framework for orchestrating complex AI agent workflows. While existing frameworks require you to define how work gets done — graphs to traverse, roles to assign, steps to sequence — Converge takes a fundamentally different approach. You define what "done" looks like: what files must exist, what quality checks must pass, what the deliverable looks like when it's finished. The framework continuously measures the distance between current state and target state and generates work to close the gap.

When things fail, Converge doesn't just retry. It writes a structured analysis (LEARN.md) of exactly what went wrong, and the next attempt reads that analysis first, applying targeted corrections. This self-correction loop means fewer failed runs, less wasted API spend, and less human intervention. The filesystem-as-plan convention means your `.converge/` directory is the execution plan — `ls` and `cat` are your debugger.

Built on 270 lines of core logic with 92% test coverage, Converge supports Claude, Gemini, Kimi, and Qwen through its multi-provider `agentfn` abstraction. It ships with reusable playbooks for encoding repeatable workflows, crash-safe checkpoints for long-running processes, and infinite hierarchical nesting (Project > Epic > Task > Subtask). Designed for businesses automating real workflows — from solo entrepreneurs scaling content production to engineering teams standardizing delivery across departments. MIT licensed.
