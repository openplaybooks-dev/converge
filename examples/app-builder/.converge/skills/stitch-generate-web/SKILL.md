# Stitch Generate Web Skill

Generate static HTML/CSS references that capture visual taste before React conversion.

## Inputs

- `.stitch/system/DESIGN.md`
- route or screen specs

## Outputs

- `.html` references
- short `.md` rationale files when requested

## Rules

- static HTML only, no React code
- express composition, layering, and typography clearly
- backgrounds and imagery should feel deliberate
- the output should be visually opinionated enough to guide later conversion
