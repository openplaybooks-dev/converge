# Taste Design Skill — React Web

Write `.stitch/system/DESIGN.md` as pure design prose. No CSS snippets, no JSX, no framework APIs.

## Inputs

- `.stitch/UX.md`
- `.stitch/screens.json`

## Output

- `.stitch/system/DESIGN.md`

## Must Define

- named visual theme
- light and dark palettes with semantic roles
- expressive Google Fonts, excluding Inter and Roboto
- spacing and radius rhythm
- surface, button, chip, modal, and hero treatments
- image-background layering rules
- motion language
- banned anti-patterns

## Constraints

- no purple/neon AI-default look
- no flat, sterile white app shells
- no generic gradients without a compositional reason
- keep the app visually bold but still readable
