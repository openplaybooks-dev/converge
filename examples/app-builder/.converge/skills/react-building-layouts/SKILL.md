# React Building Layouts Skill

Build React layouts that feel intentional, not boilerplate.

## Default Stack

- `React + TypeScript`
- Tailwind for utility layout work
- CSS variables for theme tokens

## Expectations

- prefer strong visual hierarchy
- use generated imagery where the spec calls for it
- preserve the screen's narrative structure
- split dense subtrees into local components when readability improves

## Avoid

- placeholder marketing copy
- enterprise dashboard defaults
- oversharing state through needless abstractions
- generic centered card-on-gradient compositions unless the spec demands it
