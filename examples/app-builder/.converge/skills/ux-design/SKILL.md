# UX Design Skill

Generate a complete UX specification for a **React web application**. Think in route-level pages, layered backgrounds, shell navigation, filters, modals, and animated transitions.

## Inputs

- `PRD.md`

## Output

- `.stitch/UX.md`

## Procedure

1. Read `PRD.md`.
2. Define the app vibe in design language, not code.
3. Describe each route-level screen:
   - purpose
   - page structure
   - shell chrome
   - background image treatment
   - displayed data
   - interactions
   - motion and transitions
4. Describe the navigation model.
5. Describe data and state expectations.
6. Call out required playful interactions and persisted preferences.

## Constraints

- Treat this as a browser app, not a mobile scaffold.
- Favor memorable, visual screens over generic dashboards.
- Include at least one route where the background image is part of the storytelling.
- Avoid backend assumptions.
