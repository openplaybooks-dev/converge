# Research Synthesis Skill

## When to Use This Skill

Use this skill when conducting market analysis, user research, or competitive analysis to inform product design decisions.

## Methodology

### 1. User Research

**Personas**: Create ≥2 distinct user personas with:
- **Name & Role**: e.g., "Alex, Junior Developer"
- **Demographics**: Age range, role, technical proficiency
- **Goals**: What they want to accomplish with the product
- **Pain points**: Current frustrations and workarounds
- **Behaviors**: How they interact with similar products
- **Context**: When/where/how they'll use this product
- **Quote**: A representative user statement

### 2. Market Analysis

- Market size (TAM, SAM, SOM)
- Growth rate and trends
- Key market segments
- Regulatory or technological shifts
- Underserved niches

### 3. Competitive Analysis

For ≥3 competitors:
- **Product overview**: What they offer, target market
- **Strengths**: What they do well
- **Weaknesses**: Where they fall short
- **Pricing**: Business model
- **Market position**: Where they sit
- **Differentiation opportunity**: What gap we can fill

### 4. Insights Synthesis

- Pattern matching across user pain points
- Gap analysis in competitive offerings
- Underserved user segments
- Emerging trends and opportunities

### 5. Recommendations

- Which user segments to target first (MVP focus)
- Which competitive gaps to exploit
- Which features to prioritize
- Which risks to mitigate

## Output Format

### RESEARCH_REPORT.md
```markdown
# Research Report — [Product Name]

## Executive Summary
## User Personas (→ user-personas.md)
## Market Analysis
## Competitive Landscape (→ competitive-analysis.md)
## Key Insights
## Recommendations
## Next Steps
## Sources
```

## Quality Checks

- [ ] Every insight cites specific evidence
- [ ] Every recommendation traces to an insight
- [ ] ≥3 competitors analyzed
- [ ] ≥2 distinct personas
- [ ] Personas are non-overlapping
- [ ] Market data is current (within 12 months)
- [ ] All claims sourced or flagged as assumptions
- [ ] Recommendations are actionable and prioritized
