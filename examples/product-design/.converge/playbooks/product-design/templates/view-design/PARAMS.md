# PARAMS — view-design template

Each spawn.yml invocation must supply these params:

```yaml
params:
  epicId:
    type: string
    required: true
  featureId:
    type: string
    required: true
  viewId:
    type: string
    required: true
  viewTitle:
    type: string
    required: true
  persona:
    type: string
    required: true
  priority:
    type: string
    required: true
  interactions:
    type: array
    required: true
```
