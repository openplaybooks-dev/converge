# PARAMS — feature-analysis template

Each spawn.yml invocation must supply these params:

```yaml
params:
  epicId:
    type: string
    required: true
  epicTitle:
    type: string
    required: true
  epicDescription:
    type: string
    required: true
  priority:
    type: string
    required: true
  targetPersonas:
    type: array
    required: true
```
