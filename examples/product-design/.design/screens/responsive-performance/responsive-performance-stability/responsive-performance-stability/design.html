Layout Stability

Preventing Cumulative Layout Shift (CLS) — the page should not shift content after the initial paint. These patterns ensure fixed dimensions for dynamic content.

CLS Prevention Checklist

Always set explicit width + height OR aspect-ratio on images aspect-ratio prevents browser from shifting content when image loads
Reserve space for ad slots with min-height Never load ads into zero-height containers
Use loading="lazy" on below-fold images Images outside viewport don't trigger layout recalculation on load
Avoid inserting content above existing content via JS Dynamically injected banners, cookie notices, etc. should be fixed-position or reserve height
