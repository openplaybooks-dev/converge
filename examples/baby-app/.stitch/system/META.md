# Bloom — Pregnancy & Wellness Tracker

- **App Type:** Health & Wellness / Pregnancy Tracker
- **Tags:** pregnancy, wellness, maternal health, weight tracking, mindfulness, baby development
- **Platform:** Mobile (375px base width)
- **Interaction Density:** Low
- **Target Framework:** Flutter (Material 3)

## Screens

| File | Pattern | Description |
|------|---------|-------------|
| `single-screen.html` | Single Screen | Home dashboard with greeting, hero illustration, mode selector, and stat cards grid |
| `multi-state-screen.html` | Multi-State | Weight & Nutrition screen with line chart, BMI gauge, empty/populated data states |
| `celebration-screen.html` | Celebration | Pregnancy progress milestone showing weekly achievement and baby development |

## Key Patterns

- Pastel Elevation: white cards on lavender/blush canvas with lilac-tinted shadows
- 2-column stat card grid with large numeric readouts and coral/lilac accent colors
- Bottom tab navigation with coral active indicator pill
- Spring-animated staggered card reveals and numeric count-up effects
