# Asset Specification: week-02

## Overview
Baby size comparison illustration showing a sesame seed — representing the embryo at week 2 of pregnancy. The illustration is used on the HomeScreen inside the HeroIllustrationCard widget.

## Visual Description
A single, friendly sesame seed rendered in a soft, rounded style. The seed is an elongated oval with a gentle curve and a subtle ridge line running lengthwise down the center. It is centered in the viewbox. A faint circular halo behind the seed suggests scale context. The overall feel is warm, minimal, and approachable.

## Color Palette
- Primary (seed body): #F28B8B (soft coral)
- Accent (seed highlight/ridge): #8B7ED8 (muted lilac)
- Halo/glow: #FDEEEE (blush pink)
- Background: transparent

## Dimensions
- ViewBox: 0 0 200 200
- Padding: 10% (content within 20–180 range)

## Style Notes
- Stroke width: 1.5px
- Corner radius: 8px on rectangular elements
- Flat design with subtle gradient fills for depth
- Rounded, organic shapes — no sharp edges
- Mood: friendly, reassuring

## Variants
- Light mode: colors as specified above
- Dark mode: swap halo #FDEEEE to #2A2240, keep seed colors at full saturation
