# Layer Aggregation

Synthesize findings from layer phases and produce actionable outputs for the next layer.

## Process

1. **Extract key findings** — identify the 3-5 most important discoveries
2. **Select promising areas** — from prior identification, select top areas for next layer
3. **Quality gate check** — verify minimum threshold is met
4. **Document dropped areas** — rationale for deprioritization
5. **Generate insight triggers** — what must be investigated in next layer:
   - Contradictions: findings that conflict and need resolution
   - Weak evidence: claims needing stronger support
   - Scope expansion: areas more complex than expected
   - Confirmations: expected findings validated
6. **Make recommendation** — proceed to next layer or terminate

## Insight Triggers

| Type | Description | Effect on Next Layer |
|------|-------------|---------------------|
| `contradiction` | Finding contradicts other findings | Must investigate and resolve |
| `weakEvidence` | Claim has insufficient support | Must find stronger sources |
| `scopeExpansion` | Area more complex than expected | Expand investigation scope |
| `confirmation` | Expected finding validated | Document and move focus elsewhere |
| `deadEnd` | Area explored but unproductive | Drop from further investigation |

## Quality Gate Criteria

- Layer 1: ≥3 promising areas (else terminate)
- Layer 2: cross-area insights produced (else skip Layer 3)
- Layer 3: definitive synthesis achieved (else document limitations)

## Quality Criteria

- All key findings have source citations
- Promising areas have explicit evidence strength scoring
- At least 1 insight trigger generated
- Quality gate check is explicit and documented
- Recommendation is valid (proceed_to_layer_N or terminate/skip)
