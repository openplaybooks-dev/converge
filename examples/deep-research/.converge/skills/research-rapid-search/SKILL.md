# Rapid Search

Query multiple topic areas simultaneously to understand the research landscape.

## Process

1. **Analyze research question** — identify distinct topic facets
2. **Create 5-8 queries** covering different angles:
   - Factual (what, who, when, where)
   - Analytical (why, how)
   - Comparative (X vs Y)
   - Causal (what causes, what leads to)
3. **Execute searches** for each query
4. **Record results** — query text, result count, promising sources

## Query Strategy

- Start broad to identify all facets of the question
- Use varied search terms to capture different perspectives
- Note which queries return the most promising results
- Identify gaps where more search terms are needed

## Quality Criteria

- At least 5 distinct queries covering different angles
- Each query returns relevant results
- Topics span the breadth of the research question
