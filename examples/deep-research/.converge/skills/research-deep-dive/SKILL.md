# Deep Dive Areas

Investigate each promising area from prior layer with deeper source gathering and analysis.

## Process

1. **Read prior aggregation** — get promising areas from prior layer
2. **Execute targeted searches** — gather deeper sources per area
3. **Analyze sources** — extract specific claims and evidence
4. **Extract key claims** — with source citations, note contradictions
5. **Identify knowledge gaps** — what we still don't know in each area

## Per-Area Investigation

For each promising area:
- What are the key claims and findings?
- What evidence supports each claim?
- Where do sources contradict each other?
- What evidence is weak or missing?

## Output Structure

Each area should have:
- Detailed findings with source support
- Contradictions flagged for cross-analysis
- Knowledge gaps identified
- Overall assessment of understanding

## Quality Criteria

- Each promising area has detailed investigation
- Contradictions and weak evidence are flagged
- Knowledge gaps identified per area
- Claims traced back to specific sources
