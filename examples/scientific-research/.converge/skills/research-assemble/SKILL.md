# Paper Assembly

Combine individually drafted sections into a coherent research paper.

## Process

1. Read all section files in order: abstract, introduction, literature-review, methodology, results, discussion, conclusion, references
2. Add paper title (derived from research question) and metadata
3. Check cross-section coherence:
   - Consistent terminology across sections
   - No contradictions between sections (e.g., introduction promises something discussion doesn't address)
   - Results section findings match what's discussed in discussion
   - All cited sources appear in references
4. Ensure smooth transitions between sections
5. Verify minimum total word count (2000 words)

## Output Structure

```markdown
# [Paper Title]

**Research Question**: ...
**Epoch**: N

## Abstract
[abstract content]

## 1. Introduction
[introduction content]

## 2. Literature Review
[literature review content]

## 3. Methodology
[methodology content]

## 4. Results
[results content]

## 5. Discussion
[discussion content]

## 6. Conclusion
[conclusion content]

## References
[references content]
```

## Quality Criteria

- All 8 sections present and in order
- Consistent terminology throughout
- All in-text citations appear in references
- Total word count >= 2000
- Smooth transitions between sections
