# Developer experience analysis

Think from the perspective of a developer evaluating converge for the first time. What would make them choose it — or reject it?

## What to analyze

1. **CLI experience** — is the CLI intuitive? Are commands discoverable? Are error messages helpful and actionable?
2. **Public API** — is the API clean and consistent? Are there confusing exports, unclear naming, or unnecessary complexity?
3. **Documentation** — is the README accurate? Are examples working? Is there a clear getting-started path?
4. **Onboarding friction** — try the getting-started flow. What's confusing? What's missing? Where would a new user get stuck?
5. **Biggest friction point** — identify the single biggest thing hurting developer experience
