# Task: 05-positioning/005-social-kit

Create ready-to-post social media content for the Converge launch.

**Reference**: Read `docs/converge-gtm.md` section 7 (Reddit & Community)
and `docs/brand-messaging.md` for voice.

**Create** `docs/social-kit.md` with ready-to-use posts:

1. **Twitter/X Launch Thread** (5-7 tweets):
   - Tweet 1: Hook + tagline
   - Tweet 2: The problem with current frameworks
   - Tweet 3: How convergence works (with diagram description)
   - Tweet 4: Key differentiators (filesystem-first, 270 LOC)
   - Tweet 5: Code snippet (playbook.yml example)
   - Tweet 6: Link to repo + blog post
   - Tweet 7: Call for contributors

2. **LinkedIn Post** (1 post, professional tone):
   - Why we built Converge
   - Business use cases
   - Link to repo

3. **Hacker News** (Show HN post):
   - Title: "Show HN: Converge – gap-driven convergence framework for AI agents"
   - Body: concise, technical, link-heavy
   - Follow HN conventions: no hype, lead with what it does

4. **Reddit Posts** (2-3 subreddits):
   - r/MachineLearning — technical framing
   - r/SideProject — builder framing
   - r/typescript — ecosystem framing

5. **Discord/Slack Announcement** — brief, link to GitHub

**Tone per platform**: Match each platform's culture.
Twitter: concise, punchy. LinkedIn: professional. HN: technical, understated.
Reddit: conversational, honest about limitations.
