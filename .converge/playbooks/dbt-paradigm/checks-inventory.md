## Migration plan

Phase 03 (03f-checks-migration) will extract the most common checks into `tests/*.test.md` files:
1. `tests/typecheck.test.md` — wraps `pnpm -r typecheck` with optional `--filter` arg
2. `tests/tests-green.test.md` — wraps `pnpm -r test` with optional `--filter` arg
3. `tests/file-exists.test.md` — wraps `test -f` / `test -s` with path arg
4. `tests/no-pattern.test.md` — wraps `! grep` with pattern and path args
