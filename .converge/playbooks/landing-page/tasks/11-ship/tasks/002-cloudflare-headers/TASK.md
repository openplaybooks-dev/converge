# Headers

Cloudflare Pages reads `public/_headers` to set HTTP headers per
URL pattern.

## File

```
# apps/landing/public/_headers — generated by 11-ship/002-cloudflare-headers

# Security headers — apply to every route
/*
  X-Content-Type-Options: nosniff
  X-Frame-Options: DENY
  Referrer-Policy: strict-origin-when-cross-origin
  Permissions-Policy: geolocation=(), microphone=(), camera=()
  Strict-Transport-Security: max-age=31536000; includeSubDomains; preload

# CSP — start permissive, tighten in a follow-up after measuring real usage
/*
  Content-Security-Policy: default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline'; img-src 'self' data: https:; font-src 'self' data:; connect-src 'self'; frame-ancestors 'none'

# Long cache for static assets
/_astro/*
  Cache-Control: public, max-age=31536000, immutable

# Long cache for OG images, favicons, fonts
/og/*
  Cache-Control: public, max-age=31536000, immutable

# Pagefind search index — cache, but with revalidation
/pagefind/*
  Cache-Control: public, max-age=86400

# Short cache for HTML — content can change
/*.html
  Cache-Control: public, max-age=300, must-revalidate

# RSS feed — short cache
/rss.xml
  Cache-Control: public, max-age=600
```

## Banned

- `unsafe-eval` in CSP. There's no reason a static site needs `eval()`.
- `Cache-Control: no-store` for `/_astro/*`. Those files are content-hashed; they CAN be cached for a year.
